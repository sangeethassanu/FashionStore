# FashionStore – Java Full Stack E-Commerce Web Application

FashionStore is a Java Full Stack E-Commerce Web Application developed to provide users with a simple and convenient online fashion shopping experience. Users can browse fashion products, view product details, manage their shopping cart, and place orders.

## 🚀 Technologies Used

**Frontend**
- HTML5
- CSS3
- JavaScript
- JSP

**Backend**
- Java
- Java Servlets
- JDBC
- JSTL

**Database**
- MySQL

**Tools & Technologies**
- Eclipse IDE
- Apache Tomcat
- Maven
- Git & GitHub

## ✨ Key Features

- **User Registration:** Create a new account.
- **User Login:** Secure user authentication.
- **Product Listing:** Browse available fashion products.
- **Product Details:** View product information.
- **Shopping Cart:** Add, update and manage cart items.
- **Checkout:** Proceed with the order process.
- **Order Management:** View placed orders.
- **Responsive Interface:** User-friendly shopping experience.

## 🏗️ Project Architecture

The application follows the **MVC (Model-View-Controller)** architecture.

- **Model:** Handles application data and database operations.
- **View:** JSP pages display the user interface.
- **Controller:** Java Servlets process user requests and coordinate application logic.

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/sangeethassanu/FashionStore.git
```

2. Open Eclipse IDE.

3. Import the project:
   - Select File → Import.
   - Choose Existing Maven Projects.
   - Select the downloaded FashionStore folder.
   - Click Finish.

4. Configure the MySQL database and update the database connection details in the project.

5. Build the project using Maven.

6. Configure Apache Tomcat Server.

7. Right-click the project and select **Run As → Run on Server**.

8. Open the application in your browser.

## 🗄️ Database

- Database: MySQL
- Connectivity: JDBC

Configure your local database credentials before running the application.
